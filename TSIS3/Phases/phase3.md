Phase 3 — Firebase Deployment
The CFO Bot is deployed as a live web application using Firebase Hosting, following a clean and cost-aware architecture defined by the SSOT. The system is intentionally designed to operate fully on the client side, where all mathematical calculations are executed directly in the browser using predefined formulas. This ensures that the application remains deterministic, stable, and independent from external services
The deployment architecture consists of a single-page Angular application served through Firebase Hosting. The frontend is responsible for user interaction, input validation, and cost calculation logic. Since the system does not rely on any backend services, it eliminates the need for servers, databases, or external APIs. This decision significantly reduces both technical complexity and operational cost
Firebase Hosting was selected because it provides a fast, reliable, and production-ready environment for web applications. It supports Angular deployment, offers global content delivery, and generates a public URL that allows instant access to the system. This is especially important for demonstration and evaluation, as the application must be easily accessible during the defense
The deployment process is straightforward and reproducible. The Angular application is built in production mode to optimize performance and reduce bundle size. The compiled files are then deployed using Firebase CLI, resulting in a live application that can be accessed from any device. This approach ensures that the system is not only functional but also professionally presented
The final deployed CFO Bot meets all key requirements. It is responsive across devices, handles all defined edge cases such as zero inputs and free-tier bandwidth, and provides accurate cost calculations based strictly on SSOT formulas. The system is stable, fast, and ready for real-time interaction, which makes it suitable for both academic evaluation and practical demonstration
Phase 4 — Pricing Strategy and Business Justification
The CFO Bot is built using a minimal and economically efficient cloud architecture, where every design decision is aligned with the goal of reducing unnecessary cost. The system combines an Angular frontend with Firebase Hosting, while all computational logic is executed locally in the browser. This eliminates the need for backend infrastructure and creates a lightweight yet fully functional solution
The most important principle behind this architecture is simple: avoid paying for resources that are not required. Since all formulas are fixed and defined in the SSOT, there is no need for server-side computation or dynamic pricing APIs. By keeping the logic on the client side, the system avoids costs related to virtual machines, databases, and serverless execution
From a financial perspective, this results in an extremely efficient solution. The application can operate within the free usage limits of Firebase Hosting under typical conditions. Even if usage increases, costs remain predictable and scale gradually based on traffic rather than fixed infrastructure. This makes the system sustainable, controllable, and low-risk from a business standpoint
Another important advantage is operational simplicity. Without backend services, there is no need for server management, scaling configuration, or maintenance overhead. This reduces development time and allows the team to focus on functionality and user experience rather than infrastructure issues. For an academic project, this level of simplicity is not a limitation but a strategic advantage
The system is also optimized for performance and efficiency. By executing calculations locally, it reduces latency and avoids unnecessary network requests. By not storing user data externally, it eliminates storage costs and simplifies the system design. Additionally, optimizing the frontend build reduces bandwidth usage and improves loading speed, which further enhances user experience
From a strategic perspective, the architecture remains flexible. If future requirements change, the system can be extended with additional Firebase services such as authentication or database storage. However, in the current phase, these components are intentionally excluded to maintain a clean, efficient, and cost-focused design
In conclusion, the CFO Bot represents a practical implementation of cloud economics principles. It not only calculates cloud costs for users but also demonstrates how to design a system that minimizes its own expenses. The solution is balanced, scalable, and aligned with real-world business logic, making it both academically strong and professionally relevant
