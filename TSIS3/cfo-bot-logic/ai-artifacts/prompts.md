# AI Prompts Used

## Prompt 1 — Implementation Plan
Generate a step-by-step implementation plan for a deterministic cloud cost calculator that supports compute, storage, networking, and database pricing.

## Prompt 2 — Test Cases
Generate deterministic test cases for a cloud pricing calculator using:
- compute hourly pricing
- storage per GB pricing
- bandwidth free tier and paid egress
- database instance and storage pricing

## Prompt 3 — Formula Validation
Validate the following formulas for a monthly cloud cost calculator:
- compute cost
- storage cost
- egress conversion from visitors
- bandwidth cost after free tier
- database cost
- total cost
