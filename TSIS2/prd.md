Product Requirements Document (PRD)

Requirement 1: Implement a Python function parse_csv(path) -> list[dict]
Requirement 2: The function must use csv.DictReader
Requirement 3: The function must return a list of dictionaries
Requirement 4: The function must handle FileNotFoundError and return an empty list []
Requirement 5: The function must handle malformed CSV or csv.Error and return an empty list []
Requirement 6: Security: The code must not use eval, exec, os.system, or subprocess
Requirement 7: No hardcoded secrets, API keys, or credentials
